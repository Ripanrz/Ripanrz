## About Me

Saya mahasiswa tingkat akhir **Mekatronika dan Kecerdasan Buatan di Universitas Pendidikan Indonesia (UPI)** dengan minat pada perancangan *intelligent systems* yang menghubungkan **AI, data science, embedded systems, IoT, dan industrial automation**.

Saya tertarik mengerjakan engineering problems secara end-to-end: memahami kebutuhan, mengakuisisi dan mengolah data, merancang algoritma atau kontrol, mengintegrasikan hardware dan software, lalu memvalidasi solusi melalui pengujian dan deployment.

**Engineering principle:** build with evidence, validate with tests, and improve through iteration.

## Engineering Domains

| Domain | Technical Scope |
|---|---|
| **AI & Data Science** | Machine learning, deep learning, statistical analysis, data pipeline, computer vision, NLP, LLM application, dan model evaluation. |
| **Embedded Systems & Edge AI** | Firmware development, microcontroller, sensor interfacing, edge inference, hardware–software integration, dan resource-aware design. |
| **Industrial Automation & OT** | PLC, HMI, instrumentation, industrial communication, control logic, robotics, serta integrasi proses. |
| **Software & System Engineering** | API development, containerization, test design, system documentation, workflow orchestration, dan deployment. |

## Featured Projects

### SECURE-TINY — Lightweight Hardware Cryptography

Implementasi **ASCON-AEAD128** dalam RTL dengan fokus pada datapath, control FSM, buffering, dan verifikasi fungsional. Alur kerja mencakup testbench, trusted test vectors, serta persiapan sintesis dengan **Intel DE10-Nano sebagai target platform FPGA**.

## Hardware, Devices & Platforms

| Category | Hardware / Platform | Engineering Context |
|---|---|---|
| **Microcontroller** | STM32, Arduino | Firmware, GPIO, peripheral interfacing, dan sensor integration. |
| **Single-board computer** | Raspberry Pi | Edge computing, prototyping, dan device-level application. |
| **Industrial controller** | Siemens PLC, Omron PLC, Delta PLC | Control logic, automation workflow, dan HMI integration melalui ecosystem software terkait. |
| **Robotics platform** | Dobot robotic arm | Robot programming, motion task, dan automation prototyping menggunakan DobotStudio. |
| **FPGA target** | Intel DE10-Nano | Target platform untuk desain RTL SECURE-TINY; simulasi dan verifikasi dapat dilakukan sebelum deployment ke board fisik. |
| **Instrumentation** | Sensors & actuators | Akuisisi sinyal, monitoring, dan interaksi dengan physical process. |

## Current Focus

- **Edge AI & TinyML:** model inference yang efisien untuk perangkat dengan keterbatasan memori, komputasi, dan daya.
- **Agentic AI:** tool orchestration, conversational memory, dan reliable multi-step workflows.
- **FPGA & Embedded Security:** RTL architecture, verification strategy, dan implementasi kriptografi ringan.
- **Industrial IoT & OT:** sensor connectivity, PLC integration, industrial protocols, dan edge-to-platform architecture.
- **Robotics & Simulation:** ROS 2 dan Webots untuk robot modeling, simulated sensors, node-based integration, serta motion and control.
- **Industrial Connectivity:** OPC UA, Modbus RTU/TCP, MQTT, edge gateway, dan PLC-to-platform telemetry sebagai area pendalaman.
