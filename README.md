## Tentang Saya

Saya memadukan fondasi **mekatronika** dengan **AI dan data science** untuk memahami masalah secara menyeluruh—mulai dari akuisisi data, pemrosesan, pengambilan keputusan, hingga integrasi ke sistem fisik.
